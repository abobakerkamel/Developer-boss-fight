# Roadmap

## Near term

- Replace rule thresholds with optional per-user calibration.
- Add confidence scores for static gestures.
- Use Z/depth velocity as an additional punch feature.
- Add boss-specific animated attack states synchronized to projectiles.
- Add more polished sprite packs and weapon materialization animations.
- Add platform-independent audio backend.

## Mid term

- Two-hand gesture vocabulary beyond Ultimate.
- Learned temporal classifier for swipe/punch/grab transitions.
- Better collision and physical throw behavior for Gravity Claw.
- GPU shader path (e.g. ModernGL) for distortion/glow only if profiling justifies it.
- Replay/recording mode designed for social demos.

## Long term

- Boss authoring tools driven from configuration.
- Custom level editor.
- Multiplayer/shared-camera experiments.
- Packaging as a desktop executable.
